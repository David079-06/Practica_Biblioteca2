# Colección Bruno — videojuegos

Esta primera parte permite probar la API REST de videojuegos. Abre esta carpeta con **Open Collection** en Bruno y selecciona el entorno **Local**.

Antes de enviar las peticiones, arranca la aplicación desde IntelliJ o VS Code y comprueba que MySQL está encendido y tiene la base de datos de la práctica anterior. Si los IDs no coinciden con los de tu base, cambia `videojuegoId` y `desarrolladoraId` en `environments/Local.bru`.

Prueba las peticiones numeradas en orden. La última comprueba el error 404 usando un identificador que no existe. El siguiente bloque añadirá las peticiones de socios y préstamos.
